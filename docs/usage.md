# 使用文档

## 快速开始

1. 启动：`wordpick run`（或托盘菜单 / 开机自启）
2. 首次启动弹出引导：选择提供方（DeepSeek / Kimi / Qwen / OpenAI）并粘贴 API Key
   - Key 存入系统安全存储（macOS Keychain / Windows Credential Manager），任何界面只显示后 4 位
3. 在任意应用选中一段文字 → 工具条出现在选区下方（数字键 `1` 翻译 / `2` 解释 / `3` 设置，`Esc` 关闭）
4. 点击功能 → 对话框在选区旁打开，流式输出结果

## 终端里怎么用？

终端（Terminal.app / iTerm2 / Windows Terminal 等）大多不向系统暴露选区文本：

1. 选中终端内的文字并复制（`Cmd+C` / `Ctrl+Shift+C`）
2. 按全局快捷键 `Alt+Q`（可在设置中修改）→ 工具条在光标处弹出
3. 正常使用翻译 / 解释

## 对话框操作

| 操作 | 说明 |
| --- | --- |
| 📌 钉住 | 置顶显示、点击外部不消失，可与其它应用并行；再次点击取消 |
| 拖拽标题栏 | 移动窗口（始终约束在屏幕内） |
| 语言切换 | 翻译对话框顶部可手动切换源/目标语言（自动检测结果会高亮为默认值） |
| 复制 / 朗读 | 译文一键复制或语音朗读 |
| 追问 | 底部输入框继续提问，自动携带原文与对话历史 |
| 停止 | 流式输出期间可随时停止，已输出内容保留 |

## 触发模式（设置中切换）

| 模式 | 行为 | 适用 |
| --- | --- | --- |
| `auto`（默认） | 监听系统选区变化，选中文本自动弹工具条 | 浏览器、编辑器、Office 等大多数应用 |
| `shortcut` | 不自动弹出，按 `Alt+Q` 读取剪贴板唤起 | 终端、远程桌面、注重隐私/低干扰 |

macOS 未授予「辅助功能」权限时会自动降级为 `shortcut` 模式并引导授权。

## 常见问题

**Q：工具条不出现？**
- 检查划词长度是否超过上限（默认 5000 字符，设置中可调）
- 检查应用是否在黑名单中
- 终端类应用请使用 `Alt+Q` 快捷键唤起
- `wordpick status` 确认后台进程在运行

**Q：报错「API Key 无效」？**
点击错误卡片上的「配置 API Key」直达设置，或检查环境变量占位符对应的变量是否已设置。

**Q：429 限流？**
该提供方请求过于频繁；翻译场景默认使用 Flash 级便宜模型，必要时在设置中更换。
